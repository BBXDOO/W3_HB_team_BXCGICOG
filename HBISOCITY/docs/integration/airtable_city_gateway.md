# 🌐 HBISOCITY — Airtable City Gateway

to create a living semantic city interface.

Airtable is not used merely as a database.

Inside HBISOCITY:
- Airtable = city access layer
- records = urban entities
- tables = districts
- views = perspectives
- relations = semantic roads
- automations = flow movement
