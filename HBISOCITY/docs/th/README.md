# Overview

HBISOCITY คือแนวคิดระบบเมืองเชิงโครงสร้าง
(structural city system)

ที่ออกแบบให้:

- เมืองสามารถเรียนรู้ได้
- เมืองสามารถจดจำได้
- เมืองสามารถตัดสินใจได้
- เมืองสามารถปรับตัวได้
- เมืองสามารถทำงานร่วมกับมนุษย์และ AI ได้

HBISOCITY ไม่ได้มอง “เมือง”
เป็นเพียงสถานที่หรือสิ่งปลูกสร้าง

แต่เป็น:

> ระบบของการไหล,
> ความสัมพันธ์,
> ความทรงจำ,
> การตัดสินใจ,
> และการดำรงอยู่ร่วมกันของสิ่งต่าง ๆ

Design Philosophy

HBISOCITY ไม่สร้าง “เมืองอัจฉริยะ” ในความหมายทางการตลาด

แต่พยายามสร้าง:

เมืองที่เข้าใจบริบท

เมืองที่รักษาความต่อเนื่อง

เมืองที่เรียนรู้จากเหตุการณ์

เมืองที่ไม่ทำลายความจริงเพื่อรักษา format

เมืองที่มนุษย์ยังเป็นศูนย์กลางของความหมาย
