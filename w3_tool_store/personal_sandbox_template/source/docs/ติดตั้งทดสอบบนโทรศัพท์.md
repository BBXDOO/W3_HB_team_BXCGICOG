# ติดตั้งชุดทดสอบบน Android (ผ่าน Termux)

ชุดนี้เป็นเว็บแอปที่รันจากโทรศัพท์ของคุณเองผ่าน `127.0.0.1:8765` และเพิ่มไอคอนบนหน้าจอหลักได้ **ยังไม่ใช่ APK** ไม่ต้องเข้าสู่ระบบแพลตฟอร์มเดิม แอปเก็บโครงการในพื้นที่ของเบราว์เซอร์บนเครื่องนี้ ข้อมูลจะผูกกับเบราว์เซอร์และที่อยู่/พอร์ตนี้

1. ดาวน์โหลดไฟล์ `W3-phone-test-v19.zip` ลงโฟลเดอร์ Downloads ของโทรศัพท์
2. เปิด Termux รัน `termux-setup-storage` แล้วอนุญาตเข้าถึงไฟล์ (หากเคยอนุญาตแล้วข้ามได้)
3. ถ้าเครื่องยังไม่มี Python หรือ unzip ให้รัน `pkg install python unzip`
4. รันคำสั่งต่อไปนี้ใน Termux:

```sh
mkdir -p ~/w3-phone-test
cd ~/w3-phone-test
unzip -o ~/storage/downloads/W3-phone-test-v19.zip
bash start.sh
```

5. เมื่อ Termux แสดง `Serving HTTP on 127.0.0.1 port 8765` เปิด Chrome บนเครื่องเดียวกันไปที่ `http://127.0.0.1:8765/`
6. ถ้าหน้าแรกแสดงขึ้น ให้เปิดเมนู Chrome แล้วเลือก **ติดตั้งแอป** หรือ **เพิ่มลงในหน้าจอหลัก** (ข้อความขึ้นกับเบราว์เซอร์) เปิดไอคอนที่เพิ่มเพื่อลองใช้งาน คง Termux เปิดไว้ระหว่างทดสอบรอบแรก
7. สร้างโครงการใหม่ ลองเพิ่มข้อมูลเอง แล้วกดบันทึกจุดอ่านใน Playtest หากต้องเก็บสำเนาข้อมูล ให้เปิดโครงการและกด **EXPORT DATA** เก็บ JSON แยกจากชุดติดตั้ง

หาก `unzip` แจ้งว่าไม่พบไฟล์ ให้ตรวจชื่อที่ดาวน์โหลดใน Downloads ก่อน หากเปิดหน้าไม่ได้ ให้ดูว่า Termux ยังรันอยู่และใช้พอร์ต `8765` ตามขั้นตอน ถ้าพอร์ตถูกใช้งานอยู่ อย่าเปลี่ยนพอร์ตโดยไม่สำรอง JSON เพราะข้อมูลในเบราว์เซอร์ผูกกับที่อยู่เดิม

**ขอบเขตการตรวจ:** ชุดนี้ผ่าน build และทดสอบว่าเว็บ/ไฟล์ JS, CSS, manifest, service worker และไอคอนตอบกลับจาก HTTP ในเครื่องแล้ว ยังไม่ได้ทดสอบการติดตั้งไอคอน การแตะ หรือการทำงานแบบออฟไลน์บนโทรศัพท์ของคุณ หากเปิดแอปได้ กรุณาแจ้งผลของขั้นที่ 5 ก่อน แล้วค่อยตรวจหน้าต่าง ๆ ทีละหน้า
