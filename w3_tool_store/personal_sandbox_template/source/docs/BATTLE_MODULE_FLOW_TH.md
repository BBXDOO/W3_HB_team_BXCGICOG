# Battle และโมดูลการ์ด — ค่าตั้งต้นที่แก้ได้

วันที่ 27 ตุลาคม 2026 · แหล่ง: W3 Personal Sandbox · เจ้าของกติกา: BBX19

โครงการใหม่มีค่าเริ่มต้น Battle เป็นสองช่วง (`ช่วงหลัก`, `ช่วงถัดไป`) และเติมมานาจากสนามธาตุละ 2 เมื่อเริ่มเทิร์นของผู้เล่นฝ่ายนั้น สูงสุดสะสมธาตุละ 10 ค่าเหล่านี้แก้ได้ใน Playtest > Battle > ตั้งค่าสนามและคำสั่ง โครงการที่ไม่ได้ใช้ Battle ไม่ต้องเริ่มการต่อสู้ โครงการเก่าที่ไม่มี config ยังสร้าง config ได้จากหน้าดังกล่าว

## ตั้งค่าการร่าย

1. สร้างตัวละครสองตัว กำหนด HP/MP/EN และค่า ACT/DEF/SPE/CRI หรือค่าความสามารถที่เพิ่มเองในหน้าตัวละคร
2. สร้างการ์ดชนิด `SKILL` และใส่ในช่องความสามารถของตัวละคร สร้างโมดูลในหน้าการ์ด เลือกใช้ใน Battle ตั้งชนิดการ์ด `SKILL` และผลเสริม แล้วเสียบโมดูลในการ์ด
3. ใน Playtest > Battle ตั้งธาตุสนาม ลำดับช่วง และแอคชั่น เลือกการ์ดต้นทาง ระบุค่าร่ายทุกธาตุ ผลหลัก และ Rule ถ้าต้องตรวจเงื่อนไขก่อนใช้
4. ผล HP/MP/EN เลือกจำนวนคงที่ หรือบวกค่าจากตัวละครผู้ใช้/อีกฝ่าย คูณตามจำนวนเต็มที่กำหนดได้ เช่น `-2 + POW × -1`; ชื่อค่าต้องมีจริงบนตัวละคร ไม่เช่นนั้นแอคชั่นไม่เกิด
5. ตั้ง Rule กับช่วงได้เพื่อให้ตรวจข้อมูลล่าสุดก่อนออกจากช่วง Rule มองเห็น `battle.self.vitals.hp`, `battle.self.attributes.ACT`, `battle.self.capabilities.POW`, `battle.opponent.status.ติดพิษ`, `battle.field.elements`, `battle.turn` และ `battle.phase` เป็นต้น

โมดูลเสริมทำงานเฉพาะเมื่อการ์ดที่ติดตั้งเป็นต้นทางของแอคชั่น, ชนิดการ์ดตรง tag และ Rule ของโมดูลผ่าน ถ้า Rule ไม่ผ่าน โมดูลนั้นไม่ให้ผล; Rule ผิดหรือหาไม่พบ แอคชั่นล้มทั้งหมด โมดูลเก่าที่ไม่มี `battleLink` ยังคงเป็นข้อมูล A/B/C ของโฟลว์เดิม การพิมพ์ข้อความใน A/B/C ไม่ถูกประมวลผลเป็นผล Battle

สถานะ เช่น `ติดพิษ` และ `มึนงง` เพิ่ม/ถอดได้ด้วยผลของแอคชั่นหรือโมดูล และใช้เป็นเงื่อนไข Rule ในรอบถัดไป ชื่อสถานะอย่างเดียวไม่มีผลเสียเลือด/เสียเทิร์นอัตโนมัติ; ถ้าต้องการผลนั้นต้องนิยามขั้นตอนหรือแอคชั่นเพิ่มเติม การตั้งค่าความเสียหายอัตโนมัติและจังหวะตอบโต้ยังไม่กำหนด

ความคืบหน้า Battle แยกจากข้อมูลต้นฉบับของโครงการ กดบันทึก/โหลดจุดอ่านใน Playtest การโหลดไม่เติมมานาหรือทำแอคชั่นซ้ำ ควรสำรอง JSON ก่อนอัปเดต APK และทดลองโครงการตัวอย่างก่อนใช้ข้อมูลสำคัญ
