# Personal Sandbox v49 — Compact layout, content controls and board

วันที่ 29 ตุลาคม 2026 · ตามคำขอ BBX19 · ส่งผ่านปุ่มอัปเดตเดิม ไม่เปิด PR

## เปลี่ยนอะไร

- พื้นดำด้าน เทาหม่น และส้มแดงตามภาพอ้างอิง ลดความสูงแถบบนเหลือ 48px; เมนูโทรศัพท์ 44px ย่อเหลือ 30px ได้ และเลื่อนรายการได้
- ย้ายพรีวิวออกจาก fixed positioning มาเป็นส่วนหนึ่งของโครงหน้าจอ ผ่าน React portal ใน shell เดียวกัน พรีวิวเต็มความกว้างใต้เมนูและพื้นที่แก้ไข ลากเส้นแบ่งเพื่อปรับสูงได้ 12–70% และจำค่าไว้
- รายการ / เพิ่มบนจอแคบแสดงแทนช่องแก้ไขชั่วคราว มีหัวแถบและเนื้อหาเลื่อนแยกกัน ไม่มีปุ่มแรกซ่อนใต้หัวแถบ
- การ์ดพรีวิวและคำสั่ง A/B/C ใช้สองคอลัมน์ที่จำกัดความกว้างจริง ยกเลิก zoom บนการ์ดขนาดตายตัว จัดข้อความยาวให้ตัดบรรทัด
- หุ่นยนต์เปิดเครื่องมือขนาดตัวหนังสือทั้งจากเมนูและแถบล่าง มีโหมดทั้งโครงการที่ไม่ต้องแตะช่องหรือครอบข้อความ ขนาด/สี/ตัวหนาอยู่ใน contentStyle ของโครงการ ไม่แก้ข้อความต้นฉบับ โหมดช่องล่าสุดใช้ทั้งช่องหากไม่ได้ครอบข้อความ; โค้ดและเงื่อนไขยังปรับขนาดการแสดงด้วยโหมดทั้งโครงการได้โดยไม่แทรก markup
- แยกปุ่มคำสั่งและคู่มือออกจากหุ่นยนต์เพื่อไม่ให้ไอคอนเดียวเปิดคนละเครื่องมือ
- บอร์ดแบบช่องมนและแบบจุด เลือกสี/ไอคอนเดิมได้ เพิ่มปรับช่อง 8–64px, แสดงพิกัด, พอดีพื้นที่ และแผงรายละเอียดพับใต้ตาราง การตั้งค่ารูปแบบบอร์ดบันทึกในโครงการ ขนาดจำนวนแถว/คอลัมน์และข้อมูลเดิมยังอยู่
- ปรับสี status/navigation bar ของ Android ให้เข้าพื้นดำ

## ตรวจสอบ

- npm run lint และ npm run build ผ่าน
- Chromium จำลองหน้าสัมผัส: เปิดครบ 11 หน้า ที่ความกว้าง 360, 412, 640px ตรวจ bounding boxes ว่าแถบบน ส่วนแก้ไข และพรีวิวไม่ทับกัน พรีวิวเต็มหน้าจอ ไม่มี document horizontal overflow
- การ์ดที่มีข้อความยาว: ตรวจขอบการ์ดไม่ล้ำคอลัมน์ซ้ายและไม่ทับคำสั่งฝั่งขวา
- เมนูย่อได้ เส้นแบ่งปรับด้วยแป้นพิมพ์ได้ และปุ่มแรกของรายการไม่ถูกหัวแถบบัง
- ปรับฟอนต์ทั้งโครงการโดยไม่เลือกช่อง และทั้งช่องโดยไม่ครอบข้อความได้
- เปลี่ยนตารางเป็นจุด ปรับพอดีพื้นที่ แก้สี/ไอคอน บันทึก เปิดใหม่ และอ่านค่าที่เก็บได้ ข้อความรายละเอียดเดิมยังอยู่
- ปุ่มอัปเดตเรียก AndroidBridge.checkUpdate เดิม
- ไม่มี uncaught page errors ในการทดสอบนี้

การตรวจนี้เป็นเบราว์เซอร์จำลอง การติดตั้งและการแสดงผลบน OPPO จริงต้องตรวจจากรุ่นที่เจ้าของอัปเดตต่อ
