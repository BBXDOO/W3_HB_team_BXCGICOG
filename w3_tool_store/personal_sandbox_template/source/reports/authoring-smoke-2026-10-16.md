# ผลตรวจโครงการตัวอย่าง — 16 ตุลาคม 2026

ใช้โครงการตัวอย่างในหน่วยความจำชื่อ **เมืองทดสอบ** ที่สร้างขึ้นใหม่ทั้งหมด ไม่มีข้อมูลผู้ใช้จริง ตัวอย่างประกอบด้วยเรื่องหลัก `MEP-1`, เรื่องย่อย `SEP_1.0`, ตัวละคร INT 4, บอร์ด 3×3, สถานที่, ไอเทมคู่มือ, อีเวนต์, การ์ดสองโมดูล, ชุดกฎ และทะเบียน Common Play อีกโครงการชื่อ **ฐานใหม่** ใช้ตรวจการแยกข้อมูล

| หน้า | สิ่งที่ตรวจ | ผล |
| --- | --- | --- |
| Home | แสดงชื่อโครงการตัวอย่าง | ผ่านการ render |
| Story | แสดง `MEP-1` และสร้างเรื่องย่อยในข้อมูลตัวอย่าง | ผ่านการ render |
| Characters | แสดงตัวละครพร้อมสถานะที่ตั้งเอง | ผ่านการ render |
| Cards | แสดงการ์ดและโมดูลในข้อมูลตัวอย่าง | ผ่านการ render |
| Board | แสดงบอร์ดประเทศไทย | ผ่านการ render |
| Locations | แสดงสถานที่หอสมุด | ผ่านการ render |
| Items | แสดงคู่มือที่ลงทะเบียน | ผ่านการ render |

ตรวจความสัมพันธ์ข้อมูล: ช่อง (1,1) พบสถานที่และอีเวนต์ที่อ้างถึง; สถานที่อ้างไอเทมที่ลงทะเบียน; บริบทจาก Playtest อ่าน INT 4; กฎอ้างคำสั่งที่พบแต่ยังไม่มีตัวประมวลผล จึงเป็น `UNKNOWN`; โมดูลแสดงข้อความสุดท้าย; อีเวนต์ที่รองรับเพิ่ม HP จาก 80 เป็น 81 ในผลการทดลอง; บันทึกและเปิดโครงการกลับได้; ไฟล์สำรองอ่านทะเบียนคำสั่งได้; โครงการใหม่ไม่มีรายการจากโครงการแรก ทุกข้อผ่าน

เพิ่มการตรวจช่องเก็บของ: รับไอเทมที่ลงทะเบียน, ปฏิเสธไอเทมไม่พบ, ป้องกันจำนวนติดลบและไอเทมไม่ซ้อนเกินหนึ่ง, นำออกจนเหลือศูนย์, บันทึกและเปิดจำนวนกลับจากจุดอ่าน, นำจุดอ่านเข้าไฟล์สำรอง และปฏิเสธจำนวนติดลบในข้อมูลที่นำเข้า ทุกข้อผ่าน

คำสั่งตรวจ: `npx esbuild tests/authoringSmoke.tsx --bundle --platform=node --format=cjs --external:react --external:react-dom/server --outfile=tests/.smoke.cjs && node tests/.smoke.cjs` และ `npm run lint && npm run build`

**ขอบเขตผลตรวจ:** การ render ฝั่งเซิร์ฟเวอร์ไม่ใช่การกดปุ่มหรือพิมพ์ผ่านหน้าจอ จึงยังไม่ได้พิสูจน์การแตะ เลื่อน ปรับขนาด คีย์บอร์ดมือถือ หรือการติดตั้ง Android ตัวปรับจำนวน inventory ผ่านการตรวจแบบโค้ด แต่คำสั่งใช้เอฟเฟกต์ไอเทมและ Common Play ยังไม่มีตัวประมวลผล ไม่ถือว่าผ่านการเล่นจริง

การแพ็ก Android ยังไม่ผ่าน: workspace นี้มี Java แต่ไม่พบ Android SDK, Gradle, adb หรือโครงการ native Android จึงยังสร้างและติดตั้ง APK เพื่อทดสอบเครื่องจริงไม่ได้ ไฟล์ ZIP เป็นซอร์สและคู่มือ ไม่ใช่ APK
