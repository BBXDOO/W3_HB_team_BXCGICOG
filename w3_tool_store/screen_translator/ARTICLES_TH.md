# บทความของฉัน — รุ่น 0.4

AM Ⅲ - BUILD · OWNER: BBX19 · MAKER: ChatGPT/Codex

## ใช้งาน

1. หน้าหลัก → **บทความของฉัน · บันทึกจากลิงก์**
2. วางลิงก์ HTTPS → **ดึงและบันทึกบทความลงเครื่อง** หรือใช้แชร์ลิงก์จากเบราว์เซอร์ → W3 แปลหน้าจอ → กดดึงและบันทึก
3. แอปบันทึกต้นฉบับก่อน แยกหัวข้อ ย่อหน้า รายการ บล็อกโค้ด และแถวตารางตาม HTML เดิม ไม่ต้องอนุญาตจับภาพหรือแสดงทับแอป
4. ตรวจภาษาต้นฉบับ → **แปล / แปลต่อ** ครั้งแรกอาจดาวน์โหลดชุดภาษา จากนั้นแปลในเครื่อง
5. สลับ **ต้นฉบับ / ไทย / ต้นฉบับคู่ไทย** และใช้ **สารบัญ** กระโดดไปหัวข้อ
6. กดพักหรือออกจากหน้าอ่าน จะเก็บคำแปลที่แปลเสร็จทีละส่วน กลับมาแปลต่อได้ ส่วนที่ยังไม่แปลจะแสดงต้นฉบับพร้อมป้าย ไม่ปล่อยว่าง
7. เปิดรายการ ค้นได้ทั้งชื่อ ลิงก์ ต้นฉบับ และคำแปล แม้ปิดอินเทอร์เน็ต
8. **เพิ่มเติม → ส่งออกเป็น Markdown** เลือกที่เก็บเอง ส่งออกตามโหมดที่กำลังอ่าน เปิดใน Obsidian หรือรวมกับเอกสารอื่นได้

## ข้อมูลอยู่ที่ไหน

- SQLite `reading.db` ในพื้นที่ข้อมูลส่วนตัวของแอป เป็นคนละส่วนกับแคช การล้างแคชไม่ลบบทความ
- ไม่ต้องอนุญาตอ่านไฟล์ทั้งเครื่อง ไม่ส่งบทความไปเก็บบนเซิร์ฟเวอร์ของ W3
- ใช้เน็ตเมื่อกดดึงลิงก์และเมื่อจำเป็นต้องดาวน์โหลดโมเดลภาษาเท่านั้นสำหรับฟังก์ชันนี้; ML Kit อาจส่ง diagnostics ตามเงื่อนไข SDK
- เก็บชื่อ URL สุดท้าย ภาษาต้นฉบับ เวลาบันทึก ข้อความตามลำดับ คำแปล และตำแหน่งรายการที่อ่านล่าสุด ไม่เก็บ HTML รูปภาพ cookies หรือรหัสผ่าน
- URL เดิมเปิดเอกสารเดิม ไม่เขียนทับคำแปล ถ้าต้องการดึงฉบับใหม่ ให้ส่งออกฉบับเดิมก่อน แล้วลบและบันทึกลิงก์อีกครั้ง
- การถอนติดตั้งหรือล้าง **ข้อมูลแอป** จะลบบทความด้วย ควรส่งออกบทความสำคัญไว้ในที่เก็บที่เลือกเอง

## ขอบเขตที่ต้องรู้

- เก็บเฉพาะหน้า URL ที่เลือก ไม่ไล่เก็บเว็บหรือทั้งเล่มอัตโนมัติ คู่มือหลายหน้าบันทึกเพิ่มทีละลิงก์
- ใช้ HTML parser เลือกเนื้อหาหลัก ไม่ใช้ WebView ไม่รัน JavaScript และไม่เข้าสู่ระบบแทนผู้ใช้ จึงไม่รองรับทุกเว็บ
- หน้าโหลดด้วย JavaScript, anti-bot, paywall หรือหน้าที่ต้องล็อกอินอาจไม่ได้เนื้อหา/ได้บางส่วน มีข้อความให้ตรวจความครบถ้วนกับเว็บเสมอ ไม่รับประกันว่าเป็นบทความเต็มทุกเว็บ
- รองรับ HTML ไม่รองรับ PDF รูป ไฟล์แนบ เสียง วิดีโอ และคำบรรยายที่ยังไม่ได้โหลด
- ไม่สร้างหัวข้อใหม่จาก AI: ใช้หัวข้อเดิมที่เว็บระบุ ถ้าไม่มีหัวข้อ แสดงย่อหน้าตามลำดับ
- ตารางเป็นข้อความแยกแถวและคั่นคอลัมน์ด้วย `|` ไม่เก็บ rowspan/colspan/สมการเป็นภาพ บล็อกโค้ดไม่ส่งแปล ส่วนข้อความ inline อาจมีศัพท์/คำสั่งที่โมเดลแปลคลาดเคลื่อน ควรเทียบต้นฉบับ
- ตรวจภาษาเบื้องต้นจาก metadata และอักษร ชุดที่รองรับคือ อังกฤษ/จีน/ญี่ปุ่น → ไทย ให้เลือกภาษาเองถ้าไม่ตรง (ญี่ปุ่นคันจิล้วนแยกจากจีนไม่ได้แน่นอน)
- จำกัด HTML ที่ดาวน์โหลด 8 MiB (หลังคลาย gzip ด้วย), ข้อความ 400,000 UTF-16 units, 2,000 ส่วน, DOM ลึก 120 ชั้น ถ้าต้องตัดข้อความมีป้ายว่าได้บางส่วน
- แปลทีละส่วนและบันทึกหลังแปลส่วนนั้นครบ เมื่อเปลี่ยนภาษาจะขอยืนยันก่อนล้างเฉพาะคำแปลเพื่อไม่ให้ปะปน ต้นฉบับไม่ถูกเขียนทับ
- การแปลหยุดเมื่อออกจากแอป ไม่มีงานแปลเบื้องหลัง/foreground service เพิ่ม แปลต่อด้วยปุ่มได้

## โครงสร้างโค้ด

`ArticleActivity` รับลิงก์/อ่าน/ค้น/สารบัญ/ส่งออก → `ArticleFetcher` ดึง HTTPS แบบจำกัดขนาดและ redirect → `ArticleExtractor` อ่าน DOM ด้วย jsoup → `ArticleStore` เก็บแยก articles/blocks ใน SQLite → ML Kit แปลแต่ละส่วนและอัปเดตเฉพาะช่องภาษาไทย

การอ่านรายการ เปิดเอกสาร และค้นหาทำจากฐานข้อมูลในเครื่อง ไม่มี network request การส่งออกใช้ Android document picker ให้เลือกปลายทาง ไม่ขอสิทธิ์พื้นที่จัดเก็บแบบกว้าง
