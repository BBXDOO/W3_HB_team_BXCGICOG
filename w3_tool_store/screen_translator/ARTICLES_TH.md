คู่มือนี้อธิบายการอ่านและจัดเก็บใน W3 แปลหน้าจอ ผู้ใช้เลือกหน้าที่จะดึง เลือกว่าจะแปลหรือบันทึกเมื่อใด และเปิดเทียบกับต้นฉบับได้ รุ่น 0.7 เพิ่มโครงสร้างเว็บไซต์และหมวดให้สารบัญ โดยใช้ต้นฉบับและคำแปลที่บันทึกไว้ในเครื่องต่อได้

## บันทึกและแปลหน้าเว็บ

1. จากหน้าหลัก กด **สารบัญ · เปิดอ่านเรื่องที่บันทึก** แล้วกด **+ เพิ่มเข้าคลัง** เพื่อวางลิงก์ HTTPS หรือแชร์ลิงก์จากเบราว์เซอร์เข้า W3 แปลหน้าจอ
2. กด **ดึงและบันทึก** เพื่อบันทึกเนื้อหาทันที หรือกด **เก็บลิงก์ไว้อ่าน** เพื่อบันทึกเฉพาะลิงก์ เมื่อกลับมาเปิดรายการที่เก็บไว้ ให้กด **ดึงเนื้อหาเพื่ออ่านและแปล**
3. ในหน้าอ่าน ตรวจภาษาต้นฉบับแล้วกด **แปล / แปลต่อ** ครั้งแรกอาจต้องดาวน์โหลดชุดภาษา หลังจากนั้นแปลในเครื่องได้
4. สลับ **ต้นฉบับ / ไทย / ต้นฉบับคู่ไทย** หรือกด **สารบัญ** ในหน้าอ่านเพื่อข้ามไปยังหัวข้อของบทความ
5. หากพักหรือออกจากหน้าอ่าน แอปจะเก็บส่วนที่แปลเสร็จไว้ เมื่อกลับมาเปิด ให้กด **แปล / แปลต่อ**
6. เมื่อต้องการสำเนา กด **เพิ่มเติม** แล้วเลือกส่งออกเป็น Markdown ตามโหมดที่กำลังอ่าน

## จัดหลายหน้าเป็นคู่มือเว็บไซต์

1. ในหน้า **สารบัญ** แตะชื่อเว็บไซต์ แล้วเลือกหมวดเพื่อดูหน้าที่บันทึกไว้ บทความเดิมจัดเข้ากลุ่มตามเว็บไซต์โดยอัตโนมัติ เปิดดูได้ใน **ยังไม่จัดหมวด**
2. เปิดบทความหรือลิงก์ที่บันทึกไว้ แล้วกด **หมวดในเว็บไซต์** พิมพ์ชื่อหมวด เช่น **อาวุธ** หรือ **แผนที่** แล้วกด **บันทึก** ใช้ชื่อหมวดเดียวกันกับหน้าอื่นในเว็บเดียวกันเพื่อให้อยู่ด้วยกัน หากต้องการคืนไปที่ **ยังไม่จัดหมวด** ให้ลบชื่อหมวดแล้วบันทึก
3. ใช้ช่องค้นหาเพื่อหาจากชื่อหน้า ลิงก์ ชื่อหมวด ต้นฉบับ หรือคำแปลที่บันทึกไว้ การค้นหาและอ่านเนื้อหาที่ดึงไว้แล้วทำได้ออฟไลน์

## อ่านการ์ดในสารบัญ

การ์ดเว็บไซต์แสดงจำนวนหน้าที่บันทึก แตะเว็บไซต์เพื่อดูหมวด แล้วแตะหมวดเพื่อเปิดรายการในหมวดนั้น การ์ดรายการระบุชนิด วันที่บันทึก และสถานะ เช่น รอดึงเนื้อหา ยังไม่แปล หรือมีคำแปลกี่ส่วน ช่องค้นหาและตัวกรองใช้ร่วมกับมุมมองที่เปิดอยู่

หลังอัปเดต ตรวจโดยเปิดเว็บไซต์หนึ่งแห่ง เปิดหมวด แล้วเปิดรายการที่แปลไว้ ตรวจว่าสถานะตรงกับเนื้อหาในหน้าอ่าน และลองย่อหรือเปิด **+ เพิ่มเข้าคลัง** ทดสอบปุ่มลอยโดยลาก **ไทย** แล้วแตะเพื่อเปิดเมนูและกลับมาย่อ

## เก็บเรื่องจากตัวแปลหน้าจอ

1. ในเมนูลอยกด **อ่านส่วนที่เห็น** แล้วกด **บันทึกเข้าเรื่อง · เปิดอ่านย้อนหลัง**
2. ตั้งชื่อและเลือกหมวด **คู่มือ / หนังสือ / เกม / อื่น ๆ** ใช้ชื่อและหมวดเดิมเมื่อต้องการเติมส่วนที่อ่านเพิ่ม
3. หน้าหลัก → **สารบัญ · เปิดอ่านเรื่องที่บันทึก** เลือกหมวดหรือค้นชื่อและข้อความ จากนั้นแตะเรื่องเพื่ออ่านหรือกด **สารบัญ** เพื่อไปยังส่วนที่บันทึก
4. เมื่อข้อความต้นฉบับตรงกันหลังปรับช่องว่าง ระบบจะเก็บคำแปลเดิมและเติมเฉพาะช่องที่ยังว่าง ข้อความใหม่เรียงตามส่วนที่จับได้ หากสองช่วงไม่มีข้อความร่วม ระบบจะเพิ่มช่วงใหม่ท้ายเรื่อง

หน้าที่เคยแปลทับจอแต่ยังไม่ได้บันทึกจะไม่มีในสารบัญ ส่วนบทความจากลิงก์ที่บันทึกไว้เดิมเปิดได้โดยเลือกเว็บไซต์และหมวดในสารบัญ

## อ่านส่วนถัดไปจากหน้าจอ

โหมด **อ่านส่วนที่เห็น** แปลจากภาพหนึ่งภาพตามพื้นที่ที่เลือก เลื่อนในกรอบเพื่ออ่านคำแปลทั้งหมดที่จับได้ แล้วกด **กลับไปเลื่อนต้นทาง** เลื่อนแอปต้นทางด้วยตัวเองและกด **อ่านส่วนที่เห็น** อีกครั้ง ใช้ชื่อและหมวดเดิมเพื่อเก็บแต่ละช่วงไว้ในเรื่องเดียวกัน สำหรับซอร์สโค้ดหรือข้อความที่คัดลอกได้ ให้ใช้หน้าวางข้อความเพื่อเก็บอักขระต้นฉบับโดยตรง

## วางข้อความและ Markdown

1. เปิด **วางข้อความ / Markdown** จากหน้าหลัก หรือจาก **สารบัญ → + เพิ่มเข้าคลัง** วางข้อความลงในแท็บ **ต้นฉบับ** และแก้ไขได้ทันที
2. เลือกภาษาต้นทางและกด **แปลเป็นไทย** หรือเขียนคำแปลเองในแท็บ **คำแปล** ทั้งสองช่องรับได้ช่องละ 200,000 ตัวอักษร
3. หน้านี้แก้ไข Markdown แบบข้อความ คงบรรทัด ช่องว่าง และเครื่องหมายจัดรูปแบบพื้นฐาน การแปลจะเว้นบล็อกโค้ด โค้ดในบรรทัด และลิงก์ Markdown แบบพื้นฐาน หากวางโค้ดดิบ ให้เลือกข้อความแล้วกด **ครอบเป็นบล็อกโค้ด** หรือกดขณะไม่มีข้อความที่เลือกเพื่อครอบทั้งช่อง
4. ตั้งชื่อและกด **บันทึก** เพื่อเปิดแก้ต่อจากหมวด **บันทึกข้อความ** ในสารบัญ กด **ส่งออก / ลบ** เพื่อเลือกบันทึกต้นฉบับหรือคำแปลเป็นไฟล์ .md แยกกัน

## ข้อมูลอยู่ที่ไหน

- SQLite `reading.db` ในพื้นที่ข้อมูลส่วนตัวของแอป เป็นคนละส่วนกับแคช การล้างแคชไม่ลบบทความ
- ไม่ต้องอนุญาตอ่านไฟล์ทั้งเครื่อง ไม่ส่งบทความไปเก็บบนเซิร์ฟเวอร์ของ W3
- ใช้เน็ตเมื่อกดดึงลิงก์และเมื่อจำเป็นต้องดาวน์โหลดโมเดลภาษาเท่านั้นสำหรับฟังก์ชันนี้ ส่วน ML Kit อาจส่ง diagnostics ตามเงื่อนไข SDK
- เก็บชื่อ URL สุดท้าย ภาษาต้นฉบับ เวลาบันทึก หมวดในเว็บไซต์ ข้อความตามลำดับ คำแปล และตำแหน่งรายการที่อ่านล่าสุด ไม่เก็บ HTML รูปภาพ cookies หรือรหัสผ่าน
- URL เดิมที่ดึงเนื้อหาแล้วจะเปิดเอกสารเดิมพร้อมคำแปลที่บันทึกไว้ ถ้าต้องการดึงฉบับใหม่ ให้ส่งออกฉบับเดิมก่อน แล้วลบและบันทึกลิงก์อีกครั้ง
- การถอนติดตั้งหรือล้าง **ข้อมูลแอป** จะลบบทความด้วย ควรส่งออกบทความสำคัญไว้ในที่เก็บที่เลือกเอง

## ขอบเขตที่ต้องรู้

- เก็บเฉพาะหน้า URL ที่เลือก ไม่ไล่เก็บเว็บหรือทั้งเล่มอัตโนมัติ คู่มือหลายหน้าบันทึกเพิ่มทีละลิงก์
- ใช้ HTML parser เลือกเนื้อหาหลัก ไม่ใช้ WebView ไม่รัน JavaScript และไม่เข้าสู่ระบบแทนผู้ใช้ จึงไม่รองรับทุกเว็บ
- หน้าโหลดด้วย JavaScript, anti-bot, paywall หรือหน้าที่ต้องล็อกอินอาจไม่ได้เนื้อหา/ได้บางส่วน มีข้อความให้ตรวจความครบถ้วนกับเว็บเสมอ ไม่รับประกันว่าเป็นบทความเต็มทุกเว็บ
- รองรับ HTML ไม่รองรับ PDF รูป ไฟล์แนบ เสียง วิดีโอ และคำบรรยายที่ยังไม่ได้โหลด
- สารบัญในหน้าใช้หัวข้อเดิมที่เว็บระบุ ถ้าไม่มีหัวข้อ แสดงย่อหน้าตามลำดับ
- ตารางเป็นข้อความแยกแถวและคั่นคอลัมน์ด้วย `|` ไม่เก็บ rowspan/colspan/สมการเป็นภาพ บล็อกโค้ดไม่ส่งแปล ส่วนข้อความ inline อาจมีศัพท์/คำสั่งที่โมเดลแปลคลาดเคลื่อน ควรเทียบต้นฉบับ
- ตรวจภาษาเบื้องต้นจาก metadata และอักษร ชุดที่รองรับคือ อังกฤษ/จีน/ญี่ปุ่น → ไทย ให้เลือกภาษาเองถ้าไม่ตรง (ญี่ปุ่นคันจิล้วนแยกจากจีนไม่ได้แน่นอน)
- จำกัด HTML ที่ดาวน์โหลด 8 MiB (หลังคลาย gzip ด้วย), ข้อความ 400,000 UTF-16 units, 2,000 ส่วน, DOM ลึก 120 ชั้น ถ้าต้องตัดข้อความมีป้ายว่าได้บางส่วน
- แปลทีละส่วนและบันทึกหลังแปลส่วนนั้นครบ เมื่อเปลี่ยนภาษาจะขอยืนยันก่อนล้างเฉพาะคำแปลเพื่อไม่ให้ปะปน ต้นฉบับไม่ถูกเขียนทับ
- การแปลหยุดเมื่อออกจากแอป ไม่มีงานแปลเบื้องหลัง/foreground service เพิ่ม แปลต่อด้วยปุ่มได้

## โครงสร้างโค้ด

`ArticleActivity` รับลิงก์/อ่าน/ค้น/สารบัญ/ส่งออก → `ArticleFetcher` ดึง HTTPS แบบจำกัดขนาดและ redirect → `ArticleExtractor` อ่าน DOM ด้วย jsoup → `ArticleStore` เก็บแยก articles/blocks ใน SQLite → ML Kit แปลแต่ละส่วนและอัปเดตเฉพาะช่องภาษาไทย

การอ่านรายการ เปิดเอกสาร และค้นหาทำจากฐานข้อมูลในเครื่อง ไม่มี network request การส่งออกใช้ Android document picker ให้เลือกปลายทาง ไม่ขอสิทธิ์พื้นที่จัดเก็บแบบกว้าง

## ตรวจผลหลังอัปเดตเป็น 0.7

1. เปิด **สารบัญ · เปิดอ่านเรื่องที่บันทึก** เลือกเว็บไซต์และ **ยังไม่จัดหมวด** แล้วเปิดบทความเดิม ตรวจคำแปลและตำแหน่งอ่านที่เคยบันทึก
2. ตั้งหมวดชื่อเดียวกันให้สองหน้าจากเว็บเดียวกัน กลับไปที่สารบัญแล้วตรวจว่าทั้งสองหน้าอยู่ในหมวดเดียวกัน
3. บันทึกลิงก์ด้วย **เก็บลิงก์ไว้อ่าน** แล้วกลับมาเปิดและกด **ดึงเนื้อหาเพื่ออ่านและแปล** ตรวจว่าหน้าเดิมเปิดอ่านได้หลังดึงเนื้อหา
4. ปิดอินเทอร์เน็ตแล้วลองค้นคำจากเนื้อหาหรือคำแปลที่เก็บไว้ และเปิดผลจากสารบัญ
