## เป้าหมาย

BBX19 ใช้งาน Android และติดข้อจำกัดภาษาในหลายแอป ต้องอ่านและตัดสินใจกดเองได้ ใช้เมนูไทย ปุ่มใหญ่ ไม่ต้องตั้ง API key มีทางปิดทันที

## หน้าและการทำงาน

| พื้นที่ | หน้าที่ |
|---|---|
| หน้าหลักพื้นอ่อน ตัวอักษรเข้ม สีเขียว | เลือกภาษา/โหมด เตรียมภาษา เริ่มและหยุด พร้อมคำอธิบายสิทธิ์ |
| ปุ่มลอย «ไทย» | แตะเปิดเมนู ลากย้าย ไม่ต้องกลับหน้าแอป |
| แปลบนจอ | กล่องไทยใต้การควบคุม Android overlay; ไม่เปลี่ยนข้อความแอปต้นทาง |
| หน้าอ่านพื้นอ่อน | ไทยตัวใหญ่ ต้นฉบับด้านล่าง เลื่อนได้ คัดลอกได้ |
| เลือกพื้นที่ | ลากกรอบหนึ่งครั้ง แล้วกรองข้อความรอบต่อไป |

## ลำดับข้อมูลจริง

ผู้ใช้เตรียมโมเดล → ผู้ใช้อนุญาต overlay และ capture → foreground service → ซ่อนหน้าต่างตนเอง → ทิ้งเฟรมเก่า → อ่านเฟรมใหม่ → OCR → กรองพื้นที่/จำกัดจำนวน → เลือก source → แปลในเครื่องหรือ cache → แสดงไทย → เว้นช่วง → รอบถัดไป

หน่วยงานที่กำลังทำมีเพียงรอบเดียว Pause/hide/stop เพิ่ม generation เพื่อไม่ให้ผลเก่ากลับมาแสดงภายหลัง หยุด session ปิด VirtualDisplay, ImageReader, projection, OCR, translators, overlay และ cache; ไม่กลับมาอ่านเองหลัง process ถูกฆ่า

## สิ่งที่ยังไม่ทำ

ประวัติถาวร, ส่งไฟล์หนังสือ, เสียงพูด, บัญชี, โฆษณา, paid API, OCR ภาษาไทย, ทำงานใน secure window, แอปกดแทนผู้ใช้ และระบบอัปเดต APK อัตโนมัติ
