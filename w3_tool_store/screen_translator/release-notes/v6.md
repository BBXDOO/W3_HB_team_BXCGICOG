- ปรับกล่องคำแปลให้พอดีกับบล็อกต้นฉบับ เมื่อภาพเปลี่ยนจะซ่อนกล่องเดิมแล้วจับตำแหน่งใหม่ในโหมดอัตโนมัติ
- กรองช่องค้นหาและข้อความหน้าจอที่รู้จัก คงชื่อเฉพาะที่รองรับและตรวจตัวเลขในประโยค
- หน้าอ่านเต็มหน้าบันทึกเข้าหมวดคู่มือ หนังสือ เกม หรืออื่น ๆ ใช้ชื่อและหมวดเดิมเพื่อเติมส่วนใหม่ในเรื่องเดิม
- เปิดเรื่องที่บันทึกจากหน้าหลักผ่านสารบัญ ค้นและย้อนอ่านแบบออฟไลน์ได้
