# รุ่น 0.5 — ปุ่มขอบชัดและกรองค่าบนจอ

2026-10-31 · OWNER: BBX19 · MAKER: ChatGPT/Codex

## เปลี่ยนอะไร

- ปุ่มลอยจากวงกลม 72 dp เป็นสี่เหลี่ยม 48 × 48 dp คำว่า «ไทย» สีดำ พื้นขาว ขอบดำ 1 dp ไม่มี gradient, blur, software shadow หรือ elevation
- แผงเมนูและปุ่มคำสั่งเป็นสี่เหลี่ยมขาวขอบดำด้วย เว้นระยะปุ่มให้เห็นแต่ละช่อง แถบหัวลากย้าย/แตะย่อได้เหมือนเดิม
- กรองแต่ละ OCR line ก่อนรวมเป็นกลุ่มข้อความ: ตัวเลขล้วน, I/l/O ปนตัวเลข, HP/MP/XP/LV/FPS และค่าหน่วยสั้น ๆ ไม่ผ่าน ไม่รวมข้ามบรรทัดที่กรองออก และใช้กรอบจากบรรทัดที่เก็บจริง
- ประโยคมีตัวเลขยังแปลได้ เช่น Collect 5 items และ第1章; หลังแปลตรวจค่าตัวเลขตามลำดับให้ตรงต้นฉบับ รวม decimal, fraction, sign, percentage และ version ถ้าเปลี่ยน/หาย/เพิ่ม จะคงต้นฉบับเฉพาะส่วนนั้น แจ้งสถานะและไม่ cache คำแปลผิด
- ล้างคำแปลรอบก่อนเมื่อเริ่มจับภาพใหม่ เพื่อลดการเห็นคำแปลเก่าระหว่างรอ OCR รอบถัดไป
- ข้อมูลบทความ/ฐานข้อมูล/กุญแจลงนามและการอัปเดตใช้ของเดิม

## การตรวจ

- เพิ่ม JUnit 6 รายการใน LanguagePolicyTest ครอบคลุมค่าบนเกม OCR สับสน ประโยคจริง จีน/ญี่ปุ่น และการรักษาตัวเลข รวมชุดเดิมควรเป็น 30 tests
- แก้ข้อทัก review เรื่อง .5 / -.5: จับทศนิยมที่ไม่มีศูนย์นำหน้าพร้อมเครื่องหมาย เปรียบเทียบ .5 กับ 0.5 ว่าเท่ากัน แต่ไม่ยอมรับ .5 → 5 หรือ -.5 → .5; ไม่เปลี่ยนวิธีเทียบ version/fraction เดิม
- ใช้ GitHub Actions สร้าง APK, รัน unit tests/lint และ Workbench APK probe บน commit ของ PR นี้ สถานะจริงดูที่ Checks ของ PR ไม่อ้างว่า build ผ่านล่วงหน้า
- สภาพแวดล้อมรอบนี้ไม่มี Android SDK/Gradle/JDK compiler ที่เคยอยู่ใน /tmp จึงไม่อ้างว่ารัน Android build ในเครื่องนี้
- ไม่มี OPPO ต่อกับระบบ ต้องทดสอบการแตะ/ลาก ความคมชัด และเกมจริงหลังอัปเดต

## ข้อจำกัดและใบทดลอง

1. ปุ่มย่อมีขอบดำชัดบนพื้นมืด/สว่าง ขนาดเล็กกว่าเดิม ไม่มีขอบแสงฟุ้ง; ลากและเปิดเมนูได้
2. ทดสอบตัวเลข 100 / 94 / 89 / 98, I 94, HP 100/120 และ FPS 60: ไม่ขึ้นคำแปลของค่าล้วน
3. ทดสอบประโยค Collect 5 items กับจีน/ญี่ปุ่นที่มีจำนวน: เนื้อหายังแปลและตัวเลขตรงเดิม
4. อ่านเต็มหน้า/แปลครั้งเดียว/อัตโนมัติ/เลือกพื้นที่/ซ่อนคำแปลยังใช้งานได้
5. บทความที่บันทึกในรุ่น 0.4 ยังเปิดได้หลังอัปเดต ไม่ต้องถอนติดตั้ง

ตัวกรองเป็น heuristic ไม่แก้ความผิดพลาดของ OCR ที่อ่านเป็นคำภาษาอังกฤษจริง ๆ ได้ทุกกรณี การคงต้นฉบับเมื่อค่าตัวเลขไม่ตรงอาจทำให้บางประโยคยังเป็นภาษาต้นฉบับ ต้องเลือกพื้นที่หรือเทียบต้นฉบับตามความเหมาะสม
