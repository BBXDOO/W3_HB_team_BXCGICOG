# BOX Human Index

These Markdown maps are navigation aids. JSON files in `wx/registry/` are the
machine-readable source of truth used by Engine-Index.

## เริ่มจากงานที่ต้องการ

- [wx:BOX / CN-Fold](by_box.md) — หา template, blueprint และเอกสารเทียบความหมายของกล่องอ้างอิง
- [Registry ของ template](../registry/template_registry.json) — ตรวจ ID และตำแหน่งที่ Engine-Index ใช้อ้างอิง
- [กลับภาพรวม Library-WX](../README.md) — ดูบทบาทของคลังและเครื่องมือค้นหา

การเดินทางที่ทดลองได้: by_box → template family → คู่มือ/ต้นแบบ หรือ by_box → mapping reference เพื่อเข้าใจ host, relation และ boundary ของ CN-Fold โดยเลือกอ่านตามงาน
