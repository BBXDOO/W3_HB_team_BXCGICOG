# 📘 MPCP Ontology Anchor & Canonical Declaration

---

## จุดยืนหลัก (Core Positioning)

**MPCP is not merely an execution orchestrator.  
It is a semantic governance and causal integrity framework.**

> หากทีม/ผู้ใช้ตีความ MPCP ว่าเป็น orchestrator แบบ workflow ทั่วไป  
> จะทำให้ระบบ drift จากเจตนาหลัก  
> โปรดยึด statement นี้เป็นศูนย์กลางของความเข้าใจ

---

## Anchor Ontology – แก่นและจุดแบ่งระดับโลกทัศน์ของระบบ

### 1. **MPCP = Semantic Governance & Causal Integrity**
- ไม่ใช่ orchestrator ทั่วไป  
- คือโปรโตคอลที่บังคับใช้ความสมบูรณ์ทางนัยและตรรกะเชิงเหตุผล (semantic governance + causal traceability)

### 2. **ROT = Truth Judiciary**
- ROT = ศาลสูงสุดเรื่อง “ความจริง”  
- ไม่ใช่ validator ธรรมดา  
- สามารถ invalid runtime output ได้ หากขัด ontology/law

### 3. **ENV LAW = Semantic State Preservation**
- LAW = เยียวยาความหมาย/เหตุผล ไม่ใช่แค่เก็บ dict/raw data  
- ต้อง preserve “execution reality” เสมอ

### 4. **BaseModew = Cognitive Unit**
- BaseModew ออกแบบเป็น entity อิสระ (agent/cognitive unit)  
- อนาคตต้อง self-routing, reflexive, policy-driven, memory continuity

### 5. **Trace = Causal Proof Graph**
- trace จริง ๆ คือ proof system ของเหตุและผล  
- รองรับ replay, rollback, proof, contradiction detect

### 6. **SUCCESS = Truth-Consistent Intended Execution**
- “success” ของระบบ = ผลลัพธ์ถูกต้องตรงตาม intent และรักษาความจริง/กฎ  
- ไม่ใช่แค่ “ไม่เกิด exception”

### 7. **W3Lgu = Language of Claim, Not Truth**
- W3Lgu คือภาษา/โครงสร้างการ declare claim  
- “Truth” แท้จริงตัดสินโดย ROT เท่านั้น

### 8. **MPCP = Execution Epistemology Platform**
- ไม่ใช่ orchestrator  
- คือแพลตฟอร์มผลิต/ตรวจสอบ knowledge:  
  truth, legitimacy, causality, semantic integrity, proof, replay

### 9. **Latent Roadmap — สิ่งที่ซ่อนใน ontology**
- ACTION trace, causal graph, logical/causal time
- replay semantics, partial/uncertain truth, hierarchy
- legitimacy/transition engine, multi-agent context, proof reconstruct

### 10. **Canonical Declaration**

> **MPCP is an ontology-driven protocol and governance framework  
> that enforces semantic integrity and causal traceability  
> for agent-based systems.**
