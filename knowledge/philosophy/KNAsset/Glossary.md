# Glossary (ศัพท์เทคนิคและตัวย่อสำคัญ)

| คำศัพท์/ตัวย่อ (EN) | คำไทย, ความหมาย | ตัวอย่างในระบบ | หมายเหตุ |
|---------------------|-------------------|-----------------|----------|
| agent               | เอเจนท์/ตัวแทนทำงานอัตโนมัติ | ChatGPTAgent, CastAgent | ส่วนที่ทำการเฉพาะจุด/ชุดความสามารถย่อย |
| plan                | แผน/แผนงาน        | {"target":..., "desc":...} | บอกสิ่งที่ต้องการจะทำ/เป้าหมาย |
| context             | บริบท             | {"user":"BBXDOO", ...} | ข้อมูลประกอบ เช่น ผู้ขอ, ลูกค้า |
| blueprint           | แม่แบบ, โครงร่าง  | blueprints/Template_agent01.md | Markdown/Jinja2/แม่แบบรายงาน |
| testcase            | ตัวอย่างทดสอบ     | input/output ที่ควรเจอ | ใช้กับ function, agent, module ใด ๆ |
| usecase             | ตัวอย่างการใช้จริง| "สรุปข้อประชุม", "วิเคราะห์ยอดขาย" | ช่วยอธิบายฟีเจอร์เป็นภาพใช้งาน |
| output              | ผลลัพธ์/สิ่งที่ได้| รายงาน, summary.md | อาจเป็น text, json, markdown |
| input               | ข้อมูลนำเข้า      | docs/meeting/abc.txt | ใช้ได้กับ doc, csv, ฯลฯ |
| commit              | บันทึกชุดโค้ด     | git commit -m "msg" | ใช้ย้อนประวัติเปลี่ยนแปลง |
| flow                | ผังการไหล, ลำดับงาน | Flowchart | สะท้อน step ของระบบ |
| orchestrator        | ตัวประสาน/ควบคุม (ระบบแม่) | cli.py ที่ run หลาย agent | ช่วย orchestration workflow ทั้งหมด |
| feature             | ฟีเจอร์, ความสามารถ | "export", "summary" | หน่วยย่อย ๆ ของระบบ |
| module              | โมดูล, กล่องฟังก์ชัน | agents/plan.py | ส่วนย่อยที่นำมาใช้รวมระบบ |
| def                 | ประกาศฟังก์ชันใน Python | def myfun(): | เป็นจุดเริ่มของกลุ่มคำสั่งย่อย |
| class               | ประกาศคลาสใน Python | class Agent: | ใช้สร้างแม่พิมพ์ของวัตถุ/agent |
| import              | นำเข้าโมดูล/ฟังก์ชัน | import os     | ให้เรียกใช้โค้ดอื่นได้ |
| return              | คืนค่า/ส่งค่ากลับจากฟังก์ชัน | return data | ปิดจบฟังก์ชัน, ส่ง output |
| main                | จุดเริ่มต้นโปรแกรม | if __name__ == "__main__": | รันอัตโนมัติเมื่อสั่ง python file |

---

> เติมศัพท์/ตัวย่อใหม่ได้ตลอด หรือเพิ่มตัวอย่างสำหรับเนื้อหา agent, plan, context, flow, blueprint, test เพิ่มในโปรเจกต์ได้ทันที
