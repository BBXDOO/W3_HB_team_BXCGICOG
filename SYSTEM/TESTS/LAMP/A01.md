# <span style="color:#ffffff;text-shadow:0 0 10px rgba(255,255,255,0.4);">Abstract</span>

<span style="color:#dbeafe;line-height:1.9;">

งานวิจัยนี้นำเสนอแนวคิดของ  
<span style="color:#67e8f9;text-shadow:0 0 10px rgba(103,232,249,0.5);">Adaptive Semantic Luminance</span>  
ซึ่งเป็นระบบการแสดงผลตัวอักษรที่ออกแบบเพื่อเพิ่มความสามารถในการรับรู้ข้อมูล  
(<span style="color:#8ec5ff;">Information Perception</span>)  
ภายใต้สภาพแสงต่ำหรือการลดความสว่างของหน้าจอ โดยไม่เพิ่มค่า luminance ของ display ทั้งระบบ

ระบบดังกล่าวใช้  
<span style="color:#c792ea;text-shadow:0 0 12px rgba(199,146,234,0.45);">Localized Glyph Illumination</span>  
ร่วมกับ  
<span style="color:#5ffff2;">Semantic Priority Layer</span>  
เพื่อเพิ่มความเด่นของ:
- พยัญชนะ
- สระ
- วรรณยุกต์
- keyword
- syntax
- warning information

ผ่านกระบวนการ:
- edge glow
- adaptive contrast
- contextual luminance allocation
- semantic illumination weighting

</span>

</div>

---

# <span style="color:#ffffff;text-shadow:0 0 12px rgba(89,183,255,0.5);">1. Research Foundation</span>

<div style="color:#d6e4ff;line-height:1.95;">

งานวิจัยด้าน  
<span style="color:#7dd3fc;">Human Visual Perception</span>  
ระบุว่าการรับรู้ของมนุษย์ตอบสนองต่อ:

- <span style="color:#93c5fd;">edge contrast</span>
- <span style="color:#67e8f9;">local luminance difference</span>
- <span style="color:#a78bfa;">spectral separation</span>
- <span style="color:#f9a8d4;">attention-guided visibility</span>

ได้มีประสิทธิภาพมากกว่าการเพิ่ม brightness แบบ uniform illumination

เมื่อ brightness ถูกลดลง:
- fine stroke ของ glyph สูญเสีย contrast
- tonal marks merge กับ background
- recognition latency เพิ่มขึ้น
- eye accommodation ทำงานหนักขึ้น

</div>

---

# <span style="color:#ffffff;text-shadow:0 0 14px rgba(95,255,242,0.4);">2. Core Technical Principle</span>

<div style="background:#09101d;padding:18px;border-radius:14px;border-left:3px solid #5ffff2;">

> <span style="color:#dffcff;font-size:16px;text-shadow:0 0 12px rgba(95,255,242,0.4);">
Allocate luminance to semantic importance instead of global display brightness.
</span>

</div>

<br>

<div style="color:#d6e4ff;line-height:1.9;">

กล่าวคือ:
- พื้นหลังและองค์ประกอบรองถูกลด brightness
- ข้อมูลสำคัญได้รับ luminous enhancement
- semantic importance มีผลต่อระดับ glow

องค์ประกอบของ luminous enhancement:
- <span style="color:#67e8f9;">edge glow</span>
- <span style="color:#c792ea;">spectral edge separation</span>
- <span style="color:#7dd3fc;">adaptive contrast</span>
- <span style="color:#ffcb6b;">semantic weighting</span>

</div>

# <span style="color:#ffffff;text-shadow:0 0 14px rgba(125,207,255,0.5);">3. Rendering Architecture</span>

<div style="background:linear-gradient(180deg,#0c1528,#08101d);padding:20px;border-radius:16px;border:1px solid rgba(125,207,255,0.12);">

### <span style="color:#67e8f9;">3.1 Background Attenuation Layer</span>
<span style="color:#dbeafe;">
ลด luminance ของ UI ทั้งระบบเพื่อควบคุม visual noise และ dark adaptation
</span>

---

### <span style="color:#c792ea;">3.2 Glyph Extraction Layer</span>
<span style="color:#dbeafe;">
แยก glyph contour, tonal region และ vowel overlap region
</span>

---

### <span style="color:#7dd3fc;">3.3 Edge Illumination Layer</span>
<span style="color:#dbeafe;">
สร้าง luminous halo รอบขอบอักขระผ่าน:
- signed distance field rendering
- gaussian glow sampling
- subpixel edge enhancement
</span>

---

### <span style="color:#ffcb6b;">3.4 Semantic Priority Layer</span>

| Semantic Type | Illumination Weight |
|---|---|
| <span style="color:#ff5370;">Error</span> | High |
| <span style="color:#67e8f9;">Keyword</span> | Medium |
| <span style="color:#c792ea;">Function</span> | Medium |
| <span style="color:#9ece6a;">String</span> | Low |

</div>

# <span style="color:#ffffff;text-shadow:0 0 12px rgba(199,146,234,0.45);">4. Perceptual Visibility Model</span>

<div style="background:#08101c;padding:18px;border-radius:16px;border:1px solid rgba(199,146,234,0.18);">

<div align="center">

## <span style="color:#dff4ff;text-shadow:0 0 18px rgba(95,191,255,0.45);">
Vₚ = (Cₑ × L𝗀 × S𝗐) − Vₙ
</span>

</div>

<br>

<span style="color:#d6e4ff;">

Where:
- <span style="color:#67e8f9;">Vₚ</span> = Perceived Visibility
- <span style="color:#7dd3fc;">Cₑ</span> = Edge Contrast
- <span style="color:#c792ea;">L𝗀</span> = Glyph Luminance
- <span style="color:#ffcb6b;">S𝗐</span> = Semantic Weight
- <span style="color:#ff5370;">Vₙ</span> = Visual Noise

</span>
