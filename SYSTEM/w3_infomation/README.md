# w3_infomation — คู่มืออ่านโครงสร้างรีโป

โฟลเดอร์นี้เก็บเอกสารโครงสร้างรีโป (ไฟล์ .html) ที่ย้ายมาจากรูท
รายงาน/หนังสือแบบอ่านต่อเนื่องอยู่ที่ `repo_events/` ที่รูท

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | คืออะไร |
|---|---|
| `W3_SMALL.html` | แผนผังโครงสร้างรีโปแบบย่อ ดูภาพรวมได้เร็ว |
| `W3_FULL.html` | แผนผังโครงสร้างแบบเต็ม ลึกถึงไฟล์ย่อย |
| `W3.html` | แผนผังโครงสร้างรุ่นกลาง (ใกล้เคียง `W3_SMALL.html`) |
| `portal.html` | หน้าพอร์ทัลรวมลิงก์เอกสารหลัก |
| `repo-structure.html` | ตารางโครงสร้างรีโป สร้างโดยสคริปต์ `repo_table.sh` ที่รูท |
| `repo_report.html` | ผลคำสั่ง `ls`/`tree` ดิบ เก็บไว้เป็นบันทึกเก่า |

หมายเหตุ: ลิงก์ในไฟล์เหล่านี้ใช้ `../../` เพื่อชี้กลับไปที่รูทของรีโป
