# Modules (โมดูล)

> ทุกโมดูลควรมี `INOTE.md` เพื่อบันทึกองค์ความรู้/การเปลี่ยนแปลง/เหตุผลเชิงการตัดสินใจ

## Standard (มาตรฐาน)
- Path: `modules/<module_name>/INOTE.md`

## What to log (ควรบันทึกอะไร)
- Purpose (ทำไว้เพื่ออะไร)
- Key decisions (การตัดสินใจสำคัญ)
- Interfaces (อินพุต/เอาต์พุต)
- Known limitations (ข้อจำกัด)
- Next improvements (พัฒนาต่อ)

## Start by copying template
- Use: `modules/_template/INOTE.md`
