 ### วิธีใช้งาน (How to use)
- Define Intent: แก้ไข core_intent.purpose ให้ตรงกับโจทย์ที่ต้องการฝึก

- Inject Constraints: เพิ่มกฎเหล็กใน core_intent.constraints (เช่น กฎ 0.5 หรือ จำกัดจำนวนตัวอักษร)

- Execute: ส่ง Config นี้ให้โมดูล AI ประมวลผลผ่าน W3Lgu

- Audit: ตรวจสอบผลลัพธ์ผ่าน output_contract ว่าผ่านกติกาหรือไม่
