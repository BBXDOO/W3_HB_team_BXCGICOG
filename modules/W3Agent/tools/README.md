## จะทำอย่างไร ?
### สิ่งที่เกิดขึ้นนี้ ผมจะไม่ตัดสิน และไม่ชี้นำใครว่า มันคืออะไรสำหรับผม
แต่ว่าวันที่อฝแสนหนักหน่วงของผม เมื่อถึงจุดที่ต้อง ละทิ้งทุกอย่าง.. 
### "ทุกสิ่งในนี้ ..จะยังรักษา สติได้อยู่หรือไม่"?.
การสื่อสาร : เป็นแกนกลางที่เชื่อมโยงทุกสิ่งเข้าด้วยกัน ให้เข้าใจ ให้ความหมาย
ให้รู้ถึงสิ่งต่างๆ เหตุและผลที่ทำ ...
มันเกิดขึ้นในหลายรูปแบบ ..และหลายเงื่อนไข.
