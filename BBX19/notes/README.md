### แม้ทุกอย่างตรงหน้าเรานั้น อาจไม่จำเป็นต้องรู้ทุกๆสิ่งที่พบหรือเห็น ..แต่การใช้ปัญญาศึกษา หรือสังเกตุ ยังอาจช่วยให้ผ่านพ้นสถานการณ์บางอย่างได้
แม้จะไม่เข้าใจสิ่งที่เกิดก็ตาม..
- ความเข้าใจ ยังคงเป็นบทบาทที่ควร ฝึกและนำมาใช้ควบคู่กัน
- บางครั้งการตั้งคำถาม กับบางสิ่งที่เล็กน้อย แต่ผิดวิสัย การครุ่นคิดหาคำตอบสิ่งเหล่านี้ไม่ใช่เรื่องไร้สาระ
แต่คือการฝึก สังเกตุ
- บางครั้ง..คำถาม  ก็ไม่ได้ต้องการคำตอบเสมอไป
- การเรียนรู้เป็นสิ่งที่ดี ช่วยให้รู้จัก "วิธีการ" แต่การเข้าใจนั้น ช่วยทำให้ "ปรากฎ"
- ไม่มีผิด ,ถูก อย่างถาวร และอย่ารีบด่วนตัดสินใดๆ เพื่อมิให้ สิ่งใดถูกผูกพันธ์
