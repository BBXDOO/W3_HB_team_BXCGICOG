 การสื่อสาร ยังเป็นสิ่งที่มีความสำคัญอย่างยิ่งยวดเสมอ มีการปรับใช้รูปแบบมากมายหลากหลายมิติ ทั้งผู้ส่งสาร และผู้รับสาร..  มีคุณภาพและจุดมุ่งหมายแตกต่างกันไป 
    
    AMS : README.md  
    รูปแบบนี้เกิดขึ้นมาด้วยวัตถุประสงค์ที่เฉพาะเจาะจง โดยจะใช้แยกตาม Group ของเอกสารหลัก 4 ชนิด คือ..
    
    1. Build.
    : เอกสาร กลุ่มนี้ครอบคลุมเนื้อหาดังนี้
    - คอนเซบ ต้นแบบ
    - เอกสารประยุกต์ใช้งาน ,แนวคิดการผสมสาร หรือวิธีการนำไปสร้าง / ปฎิบัติ โดยมีการกำหนดรูปแบบผลลัพธ์ ที่ชัดเจน ,เข้าใจได้
    - test ,code ต้นแบบ.
    
    README ของ Build Group นี้จะทำหน้าที่หลักๆคือ การทำความเข้าใจเนื้อหาเอกสาร ต้นแบบ ,แนวคิด ,ที่มาที่ไป รวมถึงยังสามารถไล่สอบย้อนจาก ชุดโค้ดปลายทางที่เกิดขึ้นนั้น สอดคล้องกับ ต้นแบบหรือไม่อย่างไร เป็นต้น.
    
    สามารถ สร้างเส้นทางเชื่อมโยงถึง ระบบ หรือส่วนอื่นๆที่ทำหน้าที่สอดคล้องกัน ,ติดต่อสื่อสารกัน เพื่อใช้ดูกลไกการทำงานว่า มีลักษณะแบบไหน อย่างไร โดยไม่ทำลายแนวค้นตั้งต้น.
    
    AMS ใช้ฟิลด์ ใน README โดยแบ่งออกเป็น 3 ส่วนหลักๆคือ
    
    1. Head line
    : ใช้ 4 บรรทัดแรก แสดง identity ของเอกสาร
    
    2. Body line
    : ใช้ บรรทัดที่5 ลงมาจนจบ เนื้อหาหรือ info ของเอกสาร.
    
    3. Movement line
    : ส่วนนี้ จะทำหน้าที่ระบุว่า ในระดับ folder ที่เอกสารนี้อยู่นั้น มีอะไรบ้าง แต่ละโฟลเดอร์ในนี้ คืออะไร รวมถึง ไฟล์ต่างๆ 
    : จากตรงนี้ยังสามารถเพิ่ม text link เพื่อสร้างทางลัดไปยังเอกสารที่เกี่ยวข้องได้
    
    Boundary : AMS จะกำหนดให้ README  อธิบาย สภาพแวดล้อม ,พื้นที่ ,ระดับ Folder ที่มันอยู่เท่านั้น ยกเว้นการอ้างอิง.
    
    AM-TYPE : Ⅰ,Ⅱ,Ⅲ
    ส่วนนี้คือ รูปแบบการระบุชนิด ของเนื้อหา และแตกต่างกันไปในแต่ละ Group เช่น Build
    AM Ⅰ - BUILD : ต้นแบบ ,คอนเซบ
    AM Ⅱ - BUILD : แนวคิดการประยุกต์ ,การออกแบบ
    AM Ⅲ - BUILD : Tests ,code 
    
    Template .
    README.md
    Head //
    1. Name : ( ... )
    2. AM Ⅱ - BUILD : ( System )
    3. Log time ,ID : Log = date , time ; ID = รหัสประจำเอกสารนี้
    4. * ยังไม่เปิดเผย *.
    
    Body //
    : info (all)
    
    Movement line //
    M1 : ลำดับ ว่าใน folder นี้มีอะไรบ้าง
    M2 : แสดง (links) เอกสารอื่นๆที่เกี่ยวข้อง โดยมีสองส่วนคู่กันคือ..
    - docs.* : text links.
