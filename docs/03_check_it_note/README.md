# Check IT Note (บันทึกตรวจทาน)

> Purpose: For external AI chatbot context to review specific content precisely.
> วัตถุประสงค์: ใช้เป็นบริบทให้เอไอภายนอกช่วย “ตรวจทาน” เนื้อหาเฉพาะเรื่องแบบไม่หลุดประเด็น

## When to use (ใช้เมื่อไร)
- Before publishing / ก่อนเผยแพร่สู่ภายนอก
- Before sending to stakeholders / ก่อนส่งให้ผู้เกี่ยวข้อง
- When content could be misunderstood / เมื่อเนื้อหาเสี่ยงถูกเข้าใจผิด

## How to write (วิธีเขียนให้ได้ผล)
1) Paste the exact content (วางเนื้อหาจริงแบบไม่แก้ไข)
2) State what you want checked (บอกว่าจะให้ตรวจอะไร)
3) Provide constraints (ให้ข้อจำกัด/บริบทหน้างาน)

## Template (แม่แบบ)
### A) Content to review (เนื้อหาที่ให้ตรวจ)
```
<PASTE HERE>
```

### B) Check goals (เป้าหมายการตรวจ)
- Clarity / ความชัดเจน:
- Factual accuracy / ความถูกต้องเชิงข้อเท็จจริง:
- Tone / โทนคำพูด (ไม่อวดดี ไม่กดดัน):
- Actionability / ใช้ทำงานต่อได้จริง:

### C) Constraints & context (ข้อจำกัดและบริบท)
- Time pressure / แรงกดดันเวลา:
- Audience / กลุ่มผู้อ่าน:
- Sensitive topics / ประเด็นอ่อนไหว:

### D) Output format requested (รูปแบบผลลัพธ์ที่ต้องการ)
- [ ] Short bullets only (สั้นเป็นบูลเล็ต)
- [ ] Provide revised version (เสนอฉบับปรับแก้)
- [ ] List risks & mitigations (ระบุความเสี่ยงและทางลดความเสี่ยง)

## Quick checklist (เช็คลิสต์เร็ว)
- Is it blocking or enabling progress? (ขวางทางหรือช่วยให้ไปต่อ?)
- Any unverified assumptions? (มีการเชื่อมโยงเองไหม?)
- Can someone act on it within minutes? (ทำตามได้ภายในไม่กี่นาทีไหม?)
