# แผนของ Codex

แผนการพัฒนาจะอยู่ที่นี่เมื่อ Codex ต้องการเก็บแผนเฉพาะสาขาไว้
เพื่อการทบทวน แผนควรระบุ:

- เจตนา
- ระบบที่ได้รับผลกระทบ
- ขอบเขตที่ไม่ทับซ้อนกัน
- การทดสอบหรือการตรวจสอบที่ต้องดำเนินการ
- ผู้รับผิดชอบการส่งมอบงานต่อ
