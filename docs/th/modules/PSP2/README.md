# พื้นที่ทำงานของ PSP2

พื้นที่ทำงานส่วนตัวของ PSP2 สำหรับชั้นกระบวนการ W3

ภารกิจ: ประทับตราแพ็กเกจและกำหนดเส้นทางร่องรอยการส่งมอบงานเท่านั้น

พื้นที่ทำงานนี้รองรับชั้นกระบวนการ REDR → PSP2 → DTML → LRC2 เป็นพื้นที่ปฏิบัติงานส่วนตัวสำหรับคำขอ ร่องรอย รายงาน และบันทึก โดยไม่ได้อนุมัติการเปลี่ยนแปลงความจริงหรือข้าม Human Review / Governance Gate
