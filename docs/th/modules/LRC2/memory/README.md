# หน่วยความจำของ LRC2

พื้นที่ทำงานส่วนตัวสำหรับหน่วยความจำของ LRC2

- ภารกิจ: จัดเตรียมตัวอย่างความต่อเนื่องและบันทึกหน่วยความจำที่ไม่เปลี่ยนแปลง
- โหมดเริ่มต้น: ไม่แก้ไขข้อมูล และทบทวนก่อน
- ไม่มีการเขียนทับแหล่งข้อมูลความจริงจากโฟลเดอร์นี้
