# คำขอของ REDR

พื้นที่ทำงานส่วนตัวสำหรับคำขอของ REDR

- ภารกิจ: อ่าน จำแนก ติดป้ายกำกับ และทำสำเนาแพ็กเกจเจตนาโดยไม่เปลี่ยนแปลงข้อมูลความจริง
- โหมดเริ่มต้น: ไม่แก้ไขข้อมูล และทบทวนก่อน
- ไม่มีการเขียนทับแหล่งข้อมูลความจริงจากโฟลเดอร์นี้
