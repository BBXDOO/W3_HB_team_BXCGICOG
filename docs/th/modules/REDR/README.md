# พื้นที่ทำงานของ REDR

พื้นที่ทำงานส่วนตัวของ REDR สำหรับชั้นกระบวนการ W3

ภารกิจ: อ่าน จำแนก ติดป้ายกำกับ และทำสำเนาแพ็กเกจเจตนาโดยไม่เปลี่ยนแปลงข้อมูลความจริง

พื้นที่ทำงานนี้รองรับชั้นกระบวนการ REDR → PSP2 → DTML → LRC2 เป็นพื้นที่ปฏิบัติงานส่วนตัวสำหรับคำขอ ร่องรอย รายงาน และบันทึก โดยไม่ได้อนุมัติการเปลี่ยนแปลงข้อมูลความจริงหรือข้าม Human Review / Governance Gate
