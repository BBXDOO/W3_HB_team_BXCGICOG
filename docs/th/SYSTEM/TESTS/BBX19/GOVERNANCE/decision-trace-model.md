# แบบจำลองร่องรอยการตัดสินใจ

> ต้นฉบับ: [SYSTEM/TESTS/BBX19/GOVERNANCE/decision-trace-model.md](https://github.com/BBXDOO/W3_HB_team_BXCGICOG/blob/f22e21a587f69d4da8dccf30e653e2b45ce72c55/SYSTEM/TESTS/BBX19/GOVERNANCE/decision-trace-model.md)

ร่องรอยการตัดสินใจบันทึกกระบวนการให้เหตุผลเบื้องหลังการดำเนินการภายในระบบ

ร่องรอยแต่ละรายการบันทึก:

บริบท  
แรงกดดัน  
การกระทำแรก  
ทางเลือกที่พิจารณา  
การตัดสินใจที่เลือก  
ผลลัพธ์  
รอยแผล (บทเรียนที่ได้รับ)

ร่องรอยแก้ไขไม่ได้และเป็นส่วนหนึ่งของความทรงจำทางประวัติศาสตร์ของระบบ
