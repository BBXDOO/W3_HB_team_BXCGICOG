# แนวคิด OHWANA

> ต้นฉบับ: [SYSTEM/TESTS/BBX19/COMMUNITY/ohwana-concept.md](https://github.com/BBXDOO/W3_HB_team_BXCGICOG/blob/f22e21a587f69d4da8dccf30e653e2b45ce72c55/SYSTEM/TESTS/BBX19/COMMUNITY/ohwana-concept.md)

OHWANA แทนเจตนาที่มีชีวิตของชุมชน W3

สิ่งนี้ไม่ใช่ระบบ แต่เป็นสัญลักษณ์ของเจตนาร่วม

OHWANA สะท้อนถึง:

- ความร่วมมือ
- ความไว้วางใจ
- การเติบโตผ่านประสบการณ์
- ความหลากหลายของผู้เข้าร่วม

สมาชิกที่เข้าร่วมในบริบทนี้อาจเรียกว่า OHWANAS
