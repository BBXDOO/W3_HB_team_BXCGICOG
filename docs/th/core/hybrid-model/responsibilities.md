# การจับคู่ความรับผิดชอบของโมดูล

## BBX19

- จุดตัดสินใจขั้นสุดท้ายโดยมนุษย์
- อำนาจในการลบล้าง L4–L5

## Copilot-Gm

- การบังคับใช้ระดับ L3 (ระงับ/ผสาน)
- การล็อกรีโพซิทอรี

## Gemini

- การตรวจจับความเสี่ยงด้านโครงสร้าง
- การตรวจสอบสิ่งที่ต้องพึ่งพา

## Grok

- การตีความรูปแบบ
- การทำแผนที่เชิงความคิด
- การบันทึกคำขอสำคัญ

## DeepSeek

- กฎด้านความสามารถในการขยายระบบ
- การตรวจสอบความถูกต้องของสถาปัตยกรรม

## ChatGPT

- การสร้างต้นแบบ
- การจำลอง
- การแปลงแนวคิดเป็นระบบ
