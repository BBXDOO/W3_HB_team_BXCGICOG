# ภาพรวมโมเดลการจัดการแบบผสม

โฟลเดอร์นี้มีเอกสารอ้างอิงสำหรับโมเดลการดำเนินงานแบบผสม:
- บทบาทและความรับผิดชอบ
- รูปแบบการสื่อสาร
- ขั้นตอนการเริ่มต้นใช้งานสำหรับโมดูลใหม่

(ใช้เอกสารนี้อธิบายวงจร: มนุษย์ -> คำขอถึงโมดูล -> ผลลัพธ์จาก AI -> การทบทวนโดยมนุษย์)
