# โพรโทคอลความจำของเอเจนต์

เอเจนต์ทุกตัวต้องอ่านความจำก่อนทำงานและเขียนสรุปหลังทำงาน

## ขอบเขต

ใช้กับ: Cast, ChatGPT, Gemini, Claude, Copilot, DeepSeek, Grok และเอเจนต์ W3 ทั้งหมดในอนาคต

## กฎ

### กฎการอ่านเป็นลำดับแรก (ต้นเซสชัน)
1. อ่าน `Cast/context/session_summary.md` ก่อนเริ่มงานใด ๆ
2. กู้คืนข้อมูลจากรายการล่าสุด:
   - การตัดสินใจล่าสุด
   - งานที่ยังไม่เสร็จ
   - ความเสี่ยงที่ทราบ
   - โมดูลที่แก้ไขล่าสุด

### กฎการเขียนที่ต้องปฏิบัติ (ท้ายเซสชัน)
1. เพิ่มรายการใหม่ต่อท้าย `Cast/context/session_summary.md` หลังทุกเซสชันที่มีการทำงาน
2. ห้ามเขียนทับหรือลบรายการก่อนหน้า
3. ใช้แม่แบบที่กำหนดไว้ตอนต้นของ `session_summary.md`

### กฎการจัดเก็บถาวร (การจัดการเมื่อเนื้อหาเกินขนาด)
- หาก `Cast/context/session_summary.md` มีมากกว่า 1000 บรรทัด:
  1. ย้ายรายการที่เก่าที่สุดไปยัง `Cast/context/archive/session_summary_01.md`
  2. หากไฟล์เก็บถาวรนั้นมีมากกว่า 1000 บรรทัดเช่นกัน ให้เพิ่มเลขท้ายชื่อ (เช่น `_02.md`)
  3. เก็บรายการล่าสุดไว้ในไฟล์หลัก
