### โปรโตคอลเรียกใช้โมดูล (Module Invocation Protocol, L0)
1. มนุษย์กำหนดเจตนา (intent)
2. สร้าง `request_XXX.md` ภายใต้ `/requests/` ของโมดูลเป้าหมาย
3. โมดูลสร้างผลลัพธ์ไปที่ `reports/` หรือ `knowledge/`
4. หากมีความเสี่ยง → ส่งต่อ (escalate) ให้ Gemini
5. ผลลัพธ์ → รวม (merge) / แก้ไข (revise) / ปฏิเสธ (reject)
