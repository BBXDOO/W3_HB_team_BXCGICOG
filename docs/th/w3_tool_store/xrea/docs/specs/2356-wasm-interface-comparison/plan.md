1. ตรวจสอบ issue และไทม์ไลน์ ค้นหา PR ทั้งที่เปิดและปิดให้ครบถ้วน และทบทวน #2406
2. ขยายการตรวจสอบ core module ด้วย WABT ที่มีอยู่ใน worktree แยกต่างหาก
3. ขยายการตรวจสอบที่ producer เป็นเจ้าของให้มีข้อเท็จจริงอินเทอร์เฟซแบบมีชนิดที่เป็นทางเลือก โดยคงลายเซ็นที่ไม่รองรับไว้ในสถานะไม่ทราบและคงรูปแบบ WAT ที่ตรงตามต้นฉบับ
4. เพิ่มตัวเปรียบเทียบที่ใช้ร่วมกันซึ่งใช้เฉพาะ Evidence และสัญญาอินพุต/เอาต์พุตที่เข้มงวด
5. ลงทะเบียนเวิร์กโฟลว์ CLI/MCP ที่เพิ่มเข้ามาและเอกสารประกอบ
6. ตรวจสอบเวิร์กโฟลว์ของโมดูลต้นฉบับ รวมถึงกรณีข้อมูลผิดรูปแบบ ไม่ทราบ และการยกเลิก รันการตรวจสอบและการทบทวนโดยอิสระ แก้ไขประเด็นที่พบ และรันการตรวจสอบที่ได้รับผลกระทบอีกครั้ง
