# ความครอบคลุมของการสร้างกลับขึ้นใหม่

ต้นฉบับ: [Reconstruction coverage](https://github.com/BBXDOO/W3_HB_team_BXCGICOG/blob/f22e21a587f69d4da8dccf30e653e2b45ce72c55/w3_tool_store/xrea/docs/reconstruction-coverage.md)

`rea evaluate-reconstruction-coverage coverage.json --json` ประเมิน workspace ความครอบคลุมแบบ inline และ `boundary_id` ที่เลือก
MCP เปิดรับอินพุตเดียวกันผ่าน `evaluate_reconstruction_coverage`
ผลลัพธ์ประกอบด้วยสถานะ เหตุผล probe ที่แนะนำ และการอ้างอิง Evidence ส่วน bundle ที่ส่งมาจะเก็บระเบียนฉบับสมบูรณ์ไว้

ต้องตรวจสอบความถูกต้องของ Evidence ID และ manifest ของ bundle ก่อนการประเมิน
ระเบียนที่ถูกต้องอาจยังเป็นข้อพิสูจน์ที่ไม่เพียงพอ: สรุปจาก verifier ที่ผ่านไม่สามารถยกระดับ Evidence ที่อนุมานมาให้เป็นข้อสังเกตจากการเล่นซ้ำได้
กรณีนั้นส่งคืน `unknown` ขณะที่ระเบียนที่ขาดหายหรือถูกแก้ไขยังคงเป็นข้อผิดพลาดของอินพุต

## Evidence จาก verifier ที่เปรียบเทียบกันได้

อย่างน้อยหนึ่งระเบียนที่ข้อสังเกตล่าสุดของ verifier อ้างถึงโดยชัดแจ้งต้องรองรับอำนาจของสัญญาที่ประกาศไว้:

| อำนาจของสัญญา | แหล่ง Evidence | ความเชื่อมั่น |
| ------------------- | ----------------------------------------- | ----------------------- |
| `shipped-artifact`  | `shipped-artifact`                        | `observed` หรือ `derived` |
| `controlled-replay` | `controlled-replay`                       | `observed`              |
| `live-observation`  | `controlled-replay` หรือ `external-service` | `observed`              |
| `external`          | `external-service`                        | `observed`              |

การอ้างอิงเพื่อให้บริบทสามารถแนบมากับข้อพิสูจน์ที่เข้าเกณฑ์ได้
ระเบียนที่สังเกตได้แต่ไม่เกี่ยวข้องซึ่งอยู่ที่อื่นใน bundle ไม่สามารถแก้ผลลัพธ์ที่อ้างถึงเพียงการอนุมาน
ผลลัพธ์ที่สังเกตได้แต่เก่ากว่าไม่สามารถแทนผลลัพธ์ล่าสุดที่มีน้ำหนักอ่อน
ข้อสังเกตที่เทียบเท่ากัน ณ เวลาเดียวกันสามารถใช้ข้อพิสูจน์ที่เข้าเกณฑ์จากหนึ่งในข้อสังเกตเหล่านั้นร่วมกันได้
ส่วนการประเมินที่มีเวลาเท่ากันแต่ขัดแย้งกันยังคงไม่ทราบผล

## ข้อพิสูจน์ด้านแพ็กเกจและการผสานรวม

คำกล่าวอ้างเกี่ยวกับการบิลด์ การติดตั้งแบบสะอาด และการกำหนดเส้นทางขณะทำงาน
ต้องใช้ Evidence ขณะทำงานที่สังเกตได้ (`controlled-replay` หรือ `external-service`)
การตรวจสอบเนื้อหาแพ็กเกจและความเป็นอิสระของอำนาจสามารถใช้ Evidence แบบ `shipped-artifact` ที่สังเกตได้หรืออนุมานได้ด้วย
ข้อพิสูจน์แต่ละรายการต้องอ้างถึงระเบียนที่เข้าเกณฑ์และครอบคลุม digest ของ artifact ของ boundary ที่เลือก
การอนุมานเพียงอย่างเดียวไม่ยืนยันว่าขั้นตอนแพ็กเกจผ่านหรือล้มเหลว

ตัวประเมินรักษาที่มาของ Evidence และส่งคืนสถานะไม่ทราบที่นำไปดำเนินการต่อได้เมื่อไม่มีคุณสมบัติตามเกณฑ์
โดยไม่เปลี่ยนระเบียนที่อ้างถึงเพื่อให้อำนาจตรงกับคำประกาศของผู้เรียก
