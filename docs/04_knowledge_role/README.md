# Knowledge Role (บทบาทองค์ความรู้)

> Purpose: External AI chatbot context for logging knowledge, progress, and improvements.
> วัตถุประสงค์: ใช้เป็นบริบทให้เอไอภายนอกช่วย “บันทึกความรู้/ความคืบหน้า/การพัฒนา” อย่างต่อเนื่อง

## What to record (บันทึกอะไร)
- Decisions (การตัดสินใจ) + rationale (เหตุผล)
- Progress snapshots (ภาพรวมความคืบหน้า)
- Lessons learned (สิ่งที่เรียนรู้)
- Changes that affect many parts (สิ่งที่กระทบวงกว้าง)

## Template (แม่แบบ)
### Entry
- Date (YYYY-MM-DD):
- Topic / หัวข้อ:
- Context / บริบท:
- Facts / ข้อเท็จจริง:
- Decision / การตัดสินใจ:
- Reason / เหตุผล:
- Next actions / งานถัดไป:
- Risks / ความเสี่ยง:

## Rules (กติกา)
- Facts first, then suggestions. (ข้อเท็จจริงก่อน ค่อยข้อเสนอ)
- Avoid blaming language. (เลี่ยงภาษาตำหนิ)
- Keep it usable under time pressure. (ต้องใช้ได้แม้เวลาน้อย)
