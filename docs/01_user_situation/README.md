# User Situation Context (บริบทสถานการณ์ผู้ใช้)

> เป้าหมาย: ให้ทีม/ระบบ/เอไอเข้าใจ “ข้อจำกัดจริง” และ “สิ่งที่ต้องทำให้สำเร็จ” ภายในเวลาอันสั้น

## ใช้เอกสารนี้เมื่อไร (When to use)
- ก่อนเริ่มงาน/ก่อนเสนอคำตอบที่กระทบผู้ใช้หรือหน้างาน
- เมื่อเกิดความเข้าใจคลาดเคลื่อนด้านความคาดหวัง/เวลา/แรงกดดัน

## แม่แบบบันทึก (Template)
### 1) ภาพรวม (Overview)
- ผู้ใช้คือใคร (Who):
- บริบทงาน/สภาพแวดล้อม (Environment):
- เป้าหมายที่ต้องได้ (Outcome):

### 2) ข้อจำกัด (Constraints)
- เวลา (Time):
- ทรัพยากร/คน/เครื่องมือ (Resources):
- ความเสี่ยง/สิ่งที่กระทบวงกว้าง (Blast radius):
- ข้อจำกัดด้านเนื้อหา/นโยบาย/การเข้าถึง (Content/Policy/Access limits):
