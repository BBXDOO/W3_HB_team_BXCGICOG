# Metric Definitions (Baseline)

## PR volume
- Definition: Number of PRs opened/closed per week.
- Source: GitHub API / audit exports.

## Lead time
- Definition: Time from PR open to merge/close.
- Unit: hours.

## Risk distribution
- Definition: Share of PRs by IGET color state (green/yellow/red).
- Source: IGET scoring outputs.

## Reporting cadence
- Weekly rollup for governance review.
