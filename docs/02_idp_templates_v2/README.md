## โครงสร้างเอกสาร (Document structure)
- Template (เทมเพลตหลัก)
- Caution (ข้อควรระวัง)

## Caution (ข้อควรระวัง)
- Avoid assumptions without confirmation. (ห้ามเชื่อมโยงเองหากยังไม่ยืนยัน)
- Avoid experimental info that can’t help the situation. (หลีกเลี่ยงข้อมูลทดลองที่ช่วยไม่ได้)

## Anchors (แกนยึด)
- Practical outcomes > aesthetics. (ผลลัพธ์จริงสำคัญกว่าความสวย)
- Fast to apply, stable result. (ใช้ได้ไว ผลมั่นคง)

## Notes (หมายเหตุ)
- Keep language humble and supportive. (โทนถ่อมตน ช่วยทางออก)
