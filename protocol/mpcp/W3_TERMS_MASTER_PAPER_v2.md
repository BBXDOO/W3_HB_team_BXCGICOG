# O. W3Lgu Notation / Short Code Terms

## Room Code

รหัสห้อง เช่น Ev / Si / Ap / Ca / Cu / Re

## Room Short Code

ชื่อย่อของห้อง logic  
ใช้ใน packet / sketch / runtime contract เพื่อประหยัดพื้นที่

## Short Code

ชื่อย่อของคำหรือระบบใน W3Lgu  
ต้องมีนิยามเดียวใน glossary

## 5-Line Short Code

ชื่อย่อที่ใช้ในรูปแบบ W3Lgu 5-line packet  
ต้องอ่านได้ใน context ของ packet นั้น

## W3Lgu 5-Line Packet

packet มาตรฐาน 5 บรรทัดของ W3Lgu  
ใช้สื่อสาร intent / meaning / target / boundary / return แบบกระชับ

## 6R

short code ของ 6ROOM  
ใช้บอกชุดห้องที่ active ใน event หนึ่งตัว

## 6R Sketch

รูปย่อของ 6ROOM event เช่น `6R'Ev,Si,Cu,Re:...`  
ใช้ preview event logic โดยไม่ต้องเขียน packet เต็ม

## Logic Code

รหัส logic slot เช่น L2-C1 / L2-C3  
ใช้เชื่อม Logic27 กับ 6ROOM

# P. Cross Terms

## Cross

ภาวะที่หลายระบบหรือหลายชั้นต้องมาบรรจบกันเพื่อทำงานร่วมกัน

## Cross Point

จุดตัดที่ระบบมากกว่าหนึ่งตัวต้องใช้เงื่อนไขร่วมชั่วคราว

## Cross-X

cross-point coordinator  
เปิดเฉพาะระบบที่จำเป็นต่อ event ปัจจุบัน

## Cross-L

cross-language / cross-format adapter layer  
ใช้เมื่อ input ภายนอกต้อง normalize ก่อนเข้าระบบหลัก

## CROLL

พื้นที่หรือชุดงานของ Cross-L / CrossCode / cross-language logic

## CrossCode

รูปแบบภาษาแทรกหรือโค้ดข้ามภาษา  
ใช้เชื่อม py / json / lua / script หรือรูปแบบอื่น

## Shared Condition

เงื่อนไขร่วมที่ใช้เฉพาะจุดตัดปัจจุบัน

## Temporary Law

กฎชั่วคราวของ cross point  
หมดผลเมื่อ event หรือ cross session จบ

## Cross State

สถานะ cross ของ event: STANDBY / ACTIVE / REVIEW

## Cross Request

คำขอให้ Cross-X เปิดหรือไม่เปิด cross point

# Q. Event / E-CS Terms

## Event

สิ่งที่เกิดขึ้นและระบบต้องรับรู้

## Event Form

รูปแบบขั้นต่ำของ event  
ใช้บอกว่า event คืออะไร มาจากไหน และต้องการอะไร

## Event ID

รหัสระบุ event หนึ่งตัว

## Chain ID

รหัสระบุห่วงโซ่ event หลายตัวที่สัมพันธ์กัน

## E-CS

Event Chain System  
ระบบผูก event chain / next event / return binding

## Event Chain

ลำดับหรือโครงกิ่งของ event ที่เกี่ยวข้องกัน

## Return Binding

การผูกผลลัพธ์กลับไปยัง event / chain เดิม

## Next Event

event ถัดไปที่ระบบควรส่งต่อ

## WAIT

สถานะรอข้อมูลหรือรอ trigger เพิ่ม

## STOP

สถานะหยุด flow ปัจจุบัน

## BLOCK

สถานะถูกกันไม่ให้ดำเนินต่อด้วย boundary / risk / authority

## Trigger Event

event ที่ปลุก layer หรือ flow ที่รออยู่

## Branch Event

event ย่อยที่แตกออกจาก event หลัก

## Root Event

event แม่ของ chain หรือ flow

# R. W3Lgu 6ROOM Terms

## 6ROOM

ชั้นเลือก logic room ของ W3Lgu  
ใช้เปิดห้องที่จำเป็นต่อ event และ mark ห้องที่เหลือเป็น standby

## Room

ห้อง logic ภายใน 6ROOM  
ไม่ใช่ layer อำนาจ แต่เป็นพื้นที่หน้าที่ของ event logic

## Ev

Event room  
บอกว่าเกิดอะไรขึ้น

## Si

Situation room  
บอกสนาม / สภาพแวดล้อมตอนนั้น

## Ap

Appears room  
บอกอาการ / สัญญาณ / สิ่งที่ปรากฏ

## Ca

Cause room  
บอกสาเหตุหรือที่มา

## Cu

Cause-result room  
บอกเหตุส่งผลอย่างไร

## Re

Result room  
บอกผล / return / next / wait / stop

## Logic27

ชุด 27 slot logic selector  
ใช้เลือกตรรกะก่อน map เข้าห้อง 6ROOM

## Logic Slot

ช่องตรรกะหนึ่งตัวใน Logic27 เช่น L2-C1 หรือ L2-C3

## Logic Lens

เลนส์ประมวลผลที่วางทับ event form เพื่อเติมผลลง slot เดิม

## Bridge Lens

เลนส์แปลงผล logic หนึ่งระบบไปยังอีกระบบหนึ่ง  
เช่น Logic27 → 6ROOM

## SixRoomRuntime

runtime selector ของ 6ROOM  
อ่าน event / เลือก logic slot / เปิดห้อง / คืน contract

## Room Allocation

สถานะ ACTIVE / STANDBY / REVIEW ของแต่ละ room

## Support Required

รายการ support ที่ event ต้องใช้ต่อ เช่น MPCP_ENV / Cross-L / ROT / DTML / TEMPLATE

## Result State

สถานะผลลัพธ์ของ event เช่น SUCCESS / WAIT / STOP / REVIEW / FAIL

## Mutation Split

การแยกชนิดการเปลี่ยนแปลง: event container / source truth / env
