# บันทึกการมอบหมาย

ผู้มอบหมาย: BBX19
ผู้รับมอบหมาย: ระบุตัวแทน
ใบงาน: ระบุ request_id
สิ่งที่ให้ดำเนินการ: ระบุการตรวจ / ตอบ / บันทึก / เดินงานต่อ
ขอบเขต: ระบุผลหรือขั้นงานที่ครอบคลุม
สิ่งที่ยังต้องให้ BBX19 ตัดสินใจ: ระบุ
ระยะเวลาหรือเงื่อนไขสิ้นสุด: ระบุ
หลักฐานคำมอบหมาย: ลิงก์คำสั่งจริง

ข้อความนี้ใช้บันทึกคำมอบหมาย ตัวเชื่อม host ต้องยืนยันผู้มอบหมายจริง
ก่อนส่ง DELEGATED_CREATOR เข้า runtime ไม่ถือชื่อใน payload เป็นสิทธิ์
และไม่บันทึกว่ามนุษย์อ่านหรือตรวจเองถ้าตัวแทนเป็นผู้ดำเนินการ
