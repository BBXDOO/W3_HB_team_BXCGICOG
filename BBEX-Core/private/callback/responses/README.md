# Response Forms

AM: III / Process | Group: CONTINUE | Owner: BBX19

ระบบสร้างไฟล์ JSON ที่ผูกกับ request / intent / stage / result จริงไว้ที่นี่เมื่อคำร้อง runtime_circuit อยู่ที่ WAITING_HUMAN หรือ BLOCKED ชื่อไฟล์และ binding ให้ระบบจัดการ ผู้ใช้แก้เฉพาะคำตอบตาม [คู่มือ](../README.md)

แบบฟอร์มเปล่าไม่ใช่การอนุมัติ คำตอบหนึ่งชุดใช้ได้กับผลที่อ้างถึงเท่านั้น ผลหรือขั้นเปลี่ยนแล้วต้องใช้ฟอร์มใหม่ เก็บฟอร์มที่ตอบแล้วไว้เป็นประวัติ

ชื่อโฟลเดอร์ private เป็นการจัดพื้นที่ตามนิยาม W3 การเข้าถึงจริงขึ้นกับสิทธิ์ของรีโป้และแพลตฟอร์ม อย่าใส่ข้อมูลส่วนตัวที่ไม่จำเป็นต่อคำร้อง
